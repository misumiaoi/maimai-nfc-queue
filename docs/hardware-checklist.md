# 现场验收清单

电脑端模拟测试不能验证 PN532 的实际移卡检测、各城市交通卡/手机虚拟卡的兼容性，以及墨水屏刷新时序。合并前建议在实际硬件上检查：

| 操作 | 预期 |
| --- | --- |
| 空队列贴一张支持的卡，持续放置 30 秒 | 只加入一次，不进入退出确认，也不自动退出 |
| 移开卡，等至少 0.5 秒，再刷队列中的卡 | 显示退出确认；卡持续贴着不会退出 |
| 退出确认提示刷新完成后，继续贴卡超过 5 秒，再移开；约 4 秒后再刷 | 退出成功，证明刷新和等待移卡不消耗确认窗口 |
| 进入退出确认，移开卡，等超过 5 秒后再刷 | 再次提示确认，队列仍保留；需移开再刷才退出 |
| 不支持的卡持续放置 30 秒 | 只显示一次不支持，不持续刷新屏幕；移开后下一张支持的卡能加入 |
| 有至少 3 人排队，长按按钮 3 秒并继续按住 | 只移除一个队首；持续按住时另一张卡仍可加入（屏幕刷新期间除外）；松开再长按可再次移除 |
| 加入或退出后，等操作完成再断电重启 | 队列恢复正确，同一卡能识别为已有队列成员 |

移开和重新贴卡之间必须让读卡器连续 3 次检测不到卡。手机需要分别验证移开、再次贴近及切换虚拟卡的行为。

存储打开、盐值写入、队列读取和三种队列修改的写入失败，已在电脑端使用故障注入覆盖。遇到 `STORAGE ERROR` 时设备应暂停排卡，不能继续报告操作成功；不要在真实排队数据上用清空闪存的方式制造故障。

本次仍沿用“前 2 × 机台数 个位置标 PLAY”的原型规则。以下交互需要大家审核后再决定：按个人还是按一局推进、单人/双人上机、过号及重新排队，以及第 8 位之后如何查自己的位置。
