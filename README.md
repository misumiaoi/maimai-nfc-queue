# maimai-nfc-queue

舞萌机厅排队的最小验证：读卡器读取交通联合卡卡号，墨水屏只显示后几位。刷一次加入队尾，已在队列中的卡再刷一次会提示确认，提示显示出来后 5 秒内再刷才退出。

卡贴在读卡器上不拿开，只算刷了一次，要拿开再贴才算下一次。同一张卡拿开后 1 秒内又被读到会被忽略，避免卡放在读卡器边缘时被重复识别。

队列存在 ESP32 内部闪存里，断电后还在。不写卡，不读余额和乘车记录，不保存完整卡号。

## 能用的卡

- 交通联合卡（实体卡，以及 Apple Pay、手机钱包里的交通联合卡）：按卡号识别。iPhone 要把这张卡设为快捷交通卡，否则读卡器读到的是随机 UID，会显示 `UNSUPPORTED CARD`。
- 其他 UID 固定的 ISO14443A 卡（例如 Mifare 规格的 aime 卡、门禁卡）：读不出交通联合卡号时，按 UID 的散列识别，屏幕显示 UID 末 6 位十六进制。
- 暂不支持 FeliCa（Amusement IC、部分 aime 卡）。现在用的 Adafruit PN532 库没有 FeliCa 接口，需要换库。

## 硬件

- ESP32
- PN532（I2C，模块拨码拨到 I2C）
- 4.2 寸黑白墨水屏（Waveshare 4.2" V2 / GoodDisplay GDEY042T81）
- 管理按钮接 GPIO27 到 GND：
  - 按住 3 秒，屏幕提示 `RELEASE: REMOVE #1`，这时松开移除队首。
  - 继续按住到 10 秒，屏幕提示 `RELEASE: CLEAR ALL`，这时松开清空整个队列（例如开门前清掉前一天的队列）。
- 有源蜂鸣器的信号脚接 GPIO32（高电平鸣叫，不是无源蜂鸣器）：
  - 一声：刷卡被确认（入队、提示再刷一次退出、确认后退出）；长按到达 3 秒或 10 秒的提示；松开后成功清空队列。
  - 两声：松开后成功移除队首。
  - 三声：队列已满、无法识别的卡、找不到读卡器。

接线见 `src/config.h`。旧批次墨水屏把 `src/QueueDisplay.cpp` 里的驱动换成 `GxEPD2_420`。

## 构建

```
pio run
pio run -t upload
```

不依赖硬件的卡号解析、刷卡判定和队列逻辑可以在电脑上测：

```
test/run.sh
```

推送到 GitHub 后，`.github/workflows/ci.yml` 会自动跑上面的测试并编译固件。
