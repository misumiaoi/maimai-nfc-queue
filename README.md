# maimai-nfc-queue

舞萌机厅排队的最小验证：读卡器读取交通联合卡卡号，墨水屏显示绑定的名字；没绑定过的卡仍只显示后几位。刷一次加入队尾，已在队列中的卡再刷一次会提示确认，5 秒内再刷才退出。

队列和名字都存在 ESP32 内部闪存里，断电后还在。不写卡，不读余额和乘车记录，不保存完整卡号。卡只用本机随机盐的散列和末 6 位来表示，名字按同一个散列另外保存。

## 登记名字

板子没有键盘。名字要先输入，再贴卡：

1. 手机连上开放热点 `maimai-queue`，浏览器打开 http://192.168.4.1 ，填名字并提交。
2. 墨水屏显示这个名字。60 秒内把交通联合卡贴到读卡器上。这一下只绑定，不入队也不离队。
3. 之后这张卡再刷，队列里显示这个名字。两个相同名字会在后面加上卡号末几位。

名字只能是英文字母、数字、空格和连字符，最长 12 个字符。墨水屏现在的字体不能画中文。

已经插着 USB 时，也可以在串口（115200）输入 `NAME Alice`，取消用 `CANCEL`。串口和网页进入的是同一次等待贴卡。

网页提交的只有名字。完整卡号只在贴卡的那一下留在内存里，散列之后就丢掉，不会经 WiFi 出去，也不会写入闪存。

## 硬件

- ESP32
- PN532（I2C，模块拨码拨到 I2C）
- 4.2 寸黑白墨水屏（Waveshare 4.2" V2 / GoodDisplay GDEY042T81）
- 按钮接 GPIO27 到 GND，长按 3 秒移除队首

接线见 `src/config.h`。旧批次墨水屏把 `src/QueueDisplay.cpp` 里的驱动换成 `GxEPD2_420`。

## 构建

```
pio run
pio run -t upload
```

不依赖硬件的卡号解析、队列和名字绑定可以在电脑上测：

```
test/run.sh
```
